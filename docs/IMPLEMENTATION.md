# 实现与验证说明

## 三阶段交付

1. 单机：纯 TypeScript 世界模拟；6 艘船，3 分钟一局，三类模式，电脑导航和侧舷瞄准，炮弹连续线段碰撞，击沉/宝箱计分，复活与保护，暂停和结算。
2. 画面和移动端：Three.js 三桅木船、Canvas Jenny 船帆、程序化岛屿、云与水面波浪/菲涅耳反射，尾流/烟雾/爆炸粒子，Web Audio 海浪/炮击/命中/沉船。React 中英文界面，手机竖横屏与 iPad，双指拖船开炮、指针捕获、禁用战斗区域滚动。
3. 联机：Node + ws 权威服务器；创建私密房、房间码加入、按模式/难度自动匹配、六人上限、电脑席位替换和断线接管。客户端本地运动预测和服务器确认后的输入重放；伤害/得分/结算仅服务器计算。

## 验证

- `npm test`：真实规则测试，以及独立 WebSocket 客户端的房间、容量、匹配、输入校验、接管、快速开炮与输入超时检查。
- `node scripts/touch-check.mjs`：通过 agent-browser 的原生触控流注入双指输入；断言拖船、同时开炮、松手停船、无滚动、单机暂停和移动布局。
- `TEST_ONLINE=1 node scripts/touch-check.mjs`：同样的操作通过真实服务器，验证联机触控与联机菜单继续计时。
- `node scripts/multiplayer-check.mjs`：两个独立 Chromium 浏览器进程，创建/加入真实房间、互见、同步航行、联机菜单继续计时，并自然等待完整 180 秒验证双方结算一致。
- 截图和测试输出在 `artifacts/`。手机/iPad 检查属于浏览器模拟尺寸与触控，不等同于实物设备测试。

## 部署

## 最终结果

- 生产构建通过，输出约 784 KB（gzip 主文件合计约 217 KB）。Three.js vendor chunk 的体积提示属于构建警告，构建成功。
- 13 项规则/真实 WebSocket 集成测试全部通过。
- 双独立浏览器房间 `6MBLY` 自然运行到 00:00，双方全部名次、击沉数和积分一致，两侧控制台无错误；JSON 证据为 `artifacts/multiplayer-verification.json`。
- 触控测试分别在单机和联机通过；验证双指拖船同时右舷开炮、释放后停止、无页面滚动，以及不同菜单暂停语义。
- 中文与英文首页/战斗/指南均已检查；风暴模式可进入；宝藏模式实测 18 个宝箱/补给对象。
