# Jenny 破风者 / Jenny Stormbreakers · 中文操作说明

版本：1.1 · 2026-10-06。所有船只、岛屿、帆布、海水、云朵、粒子和声音由代码生成。

## 开始游戏

首页输入最多 18 字昵称，选择航程与游戏方式，点击“扬帆出航”。右上角“EN / 中”切换中英文；航行设置调整电脑难度、画质、音量和静音，浏览器会记住设置。

| 游戏方式 | 使用方法 |
| --- | --- |
| 人机练习 | 自己与 5 艘电脑船交战，不需要联机。 |
| 自动匹配 | 自动加入同模式、同难度的公开房间；满员会创建另一个房间。 |
| 创建房间 | 创建私人房间，将 5 位房间码或邀请链接发给朋友。 |
| 房间码加入 | 输入朋友的房间码；房间必须尚未结束且未满 6 人。 |

每个房间共有 6 个船位。真人加入接替电脑当前船位，继承该船的当前位置、血量、积分与剩余航程；真人离开后电脑接管。房间创建即开始计时，后来加入的人共享剩余时间。重新加入接替一个空闲电脑船位，不保证找回此前的船。这个设计便于随到随玩；如果希望所有人从同一起点开始，请一起创建并尽快加入。

## 航行和开炮

| 操作 | 电脑 | 手机 / iPad |
| --- | --- | --- |
| 前进 / 倒退 | W / S | 按住自己的船，拖向目标方向 |
| 转向 | A / D | 拖动方向立即改变船的朝向 |
| 停船 | 松开 W / S | 松开拖船的手指立即停船 |
| 左 / 右舷齐射 | Q / E | 点击屏幕下方左 / 右舷按钮 |
| 冲刺 | 空格 | 点击“破风冲刺” |
| 修复 | R | 点击“船体修复” |
| 补给 | F | 点击“紧急补给” |
| 菜单 | Esc 或菜单按钮 | 点击右上角菜单 |

手机可以用一根手指拖船，另一根手指同时开炮。按住船身附近开始拖动；只划海面不会移动自己的船。拖船不会旋转镜头，也不会滚动页面。船沿目标航行，仍受航速、岛屿和船只碰撞限制，不能瞬移。支持横屏和竖屏；横屏视野更宽。

火炮朝船的左右两侧发射。让敌舰位于自己侧面，距离约 100 米以内再开炮。每次齐射 3 发，每发命中造成 28 点伤害；左右舷分别装填 3 秒，可以交替射击。炮弹可能被岛屿挡住。初始保护期 2 秒，重生保护期 3 秒；保护时不能受到伤害。

## 获胜与三种航程

每局 3 分钟，击沉敌舰 +100 分，拾取金色宝箱 +35 分。最高积分获胜，同分并列；击沉数用于榜单显示排序，不改变同分并列规则。沉船后 5 秒重生，积分保留。

| 航程 | 特点 |
| --- | --- |
| 自由海战 | 航行、侧舷交锋、拾取宝箱与补给。 |
| 风暴生存 | 安全圈持续缩小；圈外每秒损失 10 点血量，必须向中心航行。 |
| 宝藏争夺 | 初始漂浮物数量由 9 增至 18，适合抢宝箱积累分数。 |

小地图中，米金色箭头是自己的船，红色箭头是其他船，金点是宝箱，绿点是补给。顶部显示血量、倒计时、积分；按钮显示独立技能冷却。游戏结束后显示全部船长积分与击沉数。

| 技能 | 效果 | 冷却 |
| --- | --- | --- |
| 破风冲刺 | 2 秒内航速由 24 提升至 42 | 12 秒 |
| 船体修复 | 恢复 35 点血量，不超过 100 | 18 秒 |
| 紧急补给 | 恢复 20 点血量，立即完成双侧装填 | 25 秒 |
| 海上绿色补给 | 恢复 25 点血量，完成双侧装填 | 拾取即生效 |

## 暂停、声音与画质

人机练习打开菜单、设置或指南会真正暂停时间、电脑、炮弹、技能冷却和声音；切到后台也暂停，回来点击“继续航行”。联机菜单明确显示“联机对局仍在继续”，其他玩家和服务器继续运行，你仍可能被攻击。打开菜单或失去焦点会停止自己的移动输入。联机断开连接后返回港湾重新加入。

手机默认“流畅”：像素比上限 1，粒子最多 180 个。精致画质最多 480 个粒子；触屏设备像素比上限 1.35，桌面 1.8。持续帧率较低时自动降低渲染分辨率。弱性能设备建议保持流畅、关闭其他占用 GPU 的页面。

声音需要点击“扬帆出航”或声音按钮后由浏览器解锁。设置中可调音量或静音；单机暂停同时暂停音频。海浪、炮声、命中、沉船、炮弹落水和拾取均有独立合成声音。可访问 `/soundcheck.html` 单独试听和检查声音。

## 本地启动

安装 Node.js 22.12 或以上版本，在源码目录执行：

```sh
npm ci
npm run build
npm start
```

打开 http://localhost:3417 。同一局域网的手机使用电脑的局域网 IP，例如 `http://192.168.1.10:3417`，并允许系统防火墙放行端口。手机的 `localhost` 指手机自身，不能用它访问电脑服务。

开发时两个终端分别执行 `npm start` 与 `npm run dev`，打开 http://localhost:5417。`npm test` 自动启动临时服务器并运行规则和真实 WebSocket 测试，无需先启动服务。

## 常见问题

- Render 免费实例空闲后会休眠，首次打开或匹配可能需要等待唤醒；看到超时提示后稍后重试。
- 房间不存在：检查房间码，房间可能已经结束或服务重启。房间只保存在内存中。
- 无法连接：检查网络，返回港湾重试。公网部署使用 HTTPS 与 WSS。
- 没有声音：点击声音按钮，检查设备静音开关、系统音量和游戏音量。
- 无法显示 3D：需要支持 WebGL 的浏览器。更新浏览器并开启硬件加速。
- 不同设备看见自己移动稍有差别：本地先预测自己的位置，服务器随后校正；血量、积分、命中、胜负均由服务器决定。

当前验证覆盖独立 Chromium 浏览器与手机 / iPad 视口、原生多点触控事件模拟。真实 iPhone Safari、iPad GPU、弱网蜂窝网络仍需实机补验，不能用电脑上的视口模拟替代实机性能结论。
