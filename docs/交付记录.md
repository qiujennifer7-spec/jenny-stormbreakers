## 本次完成

- 补齐分层海浪、炮声、命中爆炸、木材断裂沉船、落水和拾取音效；缓存噪声、10 声部上限、距离衰减 / 左右声像、静音和单机音频暂停。
- 闪光、烟雾、水花、爆炸、尾流使用一个 GPU 绘制的固定粒子池；流畅上限180、精致480。1万次特效压力测试验证没有创建额外粒子几何资源。
- Tina 航海徽章、织纹 / 缝线帆布、木纹船体、柔和浪尖、天空模拟反射、云与地平线。船体与岛屿按材质合并，减少绘制调用。
- 手机默认流畅、像素比上限、自适应降低分辨率；手机 / iPad 横竖屏、多指触控、拖船不滚动。
- 修复缺少 KeyboardEvent.code 的按键兼容、同帧短按火炮 / 冲刺丢失，以及场景未准备好时过早点击出航的问题。
- 测试服务器自动使用随机空闲端口，`npm test` 不再要求预先启动另一个服务。
- 中文说明、部署维护、逐项验收、源码打包与只读诊断。
