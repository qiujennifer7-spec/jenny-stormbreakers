## 验收边界

最多六人是每个房间的玩家上限，不代表免费单实例支持无限房间并发。多人测试在同一台 Mac 上运行独立 Chromium 浏览器，并模拟移动端视口；这验证跨视口交互和一致性，不证明真实 iOS Safari / 蜂窝弱网 / 手机 GPU 性能。正式上线后应补验一个真实手机和 iPad，尤其首次声音解锁、横竖屏切换、安全区和网络重连。

当前设计允许真人接替电脑已有成绩，与“空位随到随玩”一致，但晚加入可能继承高分。如果以后要做公平竞技榜单，应增加准备大厅、统一开局、个人身份和成绩归属，而不是直接把当前试玩分数当成持久排名。

所有验收证据均可复现；音效页只用于试听，不读取麦克风；`?verify=1` 只读诊断不改变模拟。
