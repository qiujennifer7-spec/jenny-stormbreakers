# 部署与维护

## Render 免费部署

仓库：https://github.com/qiujennifer7-spec/jenny-stormbreakers

创建一个 Web Service，连接 main 分支：

| 设置 | 值 |
| --- | --- |
| Runtime | Node |
| Region | Singapore |
| Instance | Free（$0 / 月） |
| Build | `npm ci && npm run build` |
| Start | `npm start` |
| Health check | `/health` |
| NODE_ENV | `production` |
| NODE_VERSION | `22.16.0` |

仓库 `render.yaml` 提供相同配置。前端静态文件和 `/ws` WebSocket 在一个服务、同一个域名下运行，无需数据库或第二个收费服务。服务器读取 Render 提供的 PORT。

当前账号要求银行卡 1 美元预授权。此步骤由账号持有人完成；收到完成通知后继续创建正式服务，等待部署成功，核对健康检查、首页、HTTPS/WSS、双浏览器房间与公网跨端操作，然后记录真实公网链接。源码准备完成并不代表公网已经上线。

免费实例会休眠，有冷启动；预授权也不意味着获得永不休眠的服务器。房间、积分和连接状态仅存在当前进程内存中，服务重启、部署新版本会中断对局。此版本不提供账号、持久排行榜或多个服务器之间共享房间。适合试玩和小规模邀请，不承诺商用持续在线容量。

## 检查与维护

`/health` 返回服务状态。Render 查看 Events 和 Logs；构建失败先查看 TypeScript / npm 错误。客户端有断开、满员、不存在、超时提示。服务器提供输入校验、序号去重、速率限制、350ms 移动输入过期、WebSocket 心跳、背压限制、房间回收和退出清理。

更新流程：本地构建和测试 → 提交推送 main → Render 部署 → 健康检查 → 公网双浏览器匹配验证。部署会重置现有内存房间，尽量避免有人正在对局时更新。

## 复现验收

```sh
npm ci
npm run build
npm test
npm start
```

浏览器验收需要已安装 `agent-browser`，不属于游戏运行依赖：

```sh
node scripts/audio-check.mjs
node scripts/touch-check.mjs
TEST_ONLINE=1 node scripts/touch-check.mjs
node scripts/six-player-check.mjs
node scripts/performance-check.mjs
```

`TEST_URL` 可指向正式域名，WebSocket 测试可使用 `TEST_WS_URL`。六人测试创建六个独立浏览器进程，实际通过界面匹配、移动、开炮和自然 180 秒结算；请关闭其他性能密集页面。浏览器诊断 `?verify=1` 仅输出只读服务器快照和渲染统计，不接受作弊位置或修改对局时钟。

音效试听 `/soundcheck.html`；证据存放 `artifacts/`。视口与触控模拟的通过结果不等于真实移动硬件认证。源码打包需要 Python 3（仅打包使用，游戏运行不需要），执行 `npm run package`，输出在 `delivery/`，排除依赖、Git、临时文件和源码包自身。
